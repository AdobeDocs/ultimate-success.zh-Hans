# 扩展Adobe AI代理：Audience Agent和Data Insights Agent

了解Audience Agent和Data Insights Agent如何将Ad Hoc AI使用转换为可重复、可衡量的工作流。 此活动演示了团队如何在建立成功扩展所需的治理和衡量实践的同时加快分段、受众管理、活动分析和性能诊断。

>[!VIDEO](https://video.tv.adobe.com/v/3496958/?learn=on&enablevpops)

## 您将了解的内容

在此会话中，您将探索：

- 在Adobe Experience Platform和Customer Journey Analytics中扩展AI代理背后的基本概念。
- Audience Agent和Data Insights Agent的详细功能，包括关键用例和实际应用。
- 这些代理如何协同工作以检测问题、优化定位和衡量影响。
- 从临时AI提示过渡到结构化、可重复的工作流的策略。

## 目标受众

此活动专为以下用户而设计：

- 使用Adobe Customer Journey Analytics和Adobe Experience Platform的开发人员和用户。
- 初等和中等级别的专业人员，希望增强他们对扩展AI功能的理解。
