# 创建客户体验策略以最大程度地实现AJO价值

本会议探讨如何通过将激活锚定在清晰的客户体验策略中，将其转换为可衡量的用例，并通过协调的跨职能流程执行，从Adobe Journey Optimizer中获取最大价值。 主要优势包括：提高了战略清晰度，更好地与业务优先事务协调一致，更具影响力的个性化，更高的运营效率，以及用于实现一致、可衡量的客户成果的可扩展框架。
