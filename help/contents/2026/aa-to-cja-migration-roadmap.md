# 从Adobe Analytics到Customer Journey Analytics：您的迁移路线图

通过学习确保成功的关键步骤，准备自信地从Adobe Analytics迁移到Customer Journey Analytics (CJA)。 此活动提供了全面的路线图，引导您完成过渡，涵盖从基础知识到高级迁移准备的所有内容。

>[!VIDEO](https://video.tv.adobe.com/v/3496954/?learn=on&enablevpops)

## 您将了解的内容

- **了解CJA**：了解Customer Journey Analytics是什么、它的工作方式以及它与Adobe Analytics有何不同。
- **身份和拼接**：深入了解身份策略和拼接的概念，确保客户数据的统一视图。
- **迁移准备就绪**：发现必要的准备步骤，包括变量对齐、身份策略和架构设置。
- **避免隐患**：了解常见的迁移挑战以及如何克服这些挑战。
- **最佳实践**：深入了解数据验证、回填流程和治理以实现顺利过渡。
- **实用路线图**：为您的迁移历程制定一个清晰且切实可行的计划，让您顺利离开。

## 目标受众

此活动专为以下用户而设计：

- **管理员**：负责监督迁移的技术方面。
- **领导者**：专注于战略决策和资源分配。
- **用户**：迁移后将使用CJA的最终用户。

## 日程安排

1. **CJA简介**： Customer Journey Analytics及其功能的概述。
2. **身份策略和拼接**：
   - 了解身份字段及其重要性。
   - 探索拼接方法：基于字段和基于图形。
3. **迁移准备就绪**：
   - 准备数据并调整变量。
   - 从基于会话的分析过渡到CJA的报表时间处理。
   - 设置架构和数据视图。
4. **避免常见的隐患**：
   - 解决弱身份战略问题。
   - 解决变量未对齐和数据不一致问题。
5. **正在执行迁移**：
   - 有关使用工具和验证数据的分步指南。
   - 处理历史数据回填。
6. **问答会话**：解决您的特定问题和顾虑。

加入我们，获得成功过渡到Customer Journey Analytics所需的知识和信心。 在此活动结束时，您将拥有工具、见解和最佳实践，可以开始规划您的迁移。
